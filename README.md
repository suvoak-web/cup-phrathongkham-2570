# แผนงานโครงการ CUP พระทองคำ ปีงบประมาณ 2570

แดชบอร์ดติดตาม 59 โครงการ จากไฟล์ส่วนที่ 10 สรุปแผน 2570 และแบบ 13 ช่อง

เปิด `index.html` ได้เลย ข้อมูลโครงการฝังในหน้าแล้ว

## หลายเครื่องเห็นสถานะเดียวกัน

ใช้ Google Sheet เป็นตัวเก็บสถานะ ไม่ใช้ Gist

1. นำเข้า `data/แผน2570_เทมเพลตชีต.csv`
2. แชร์ลิงก์ให้คนที่ต้องติ๊กสถานะ
3. ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ → CSV
4. ในแดชบอร์ดกด ตั้งค่า Google Sheet แล้ววางลิงก์ที่เผยแพร่

คอลัมน์ที่หน้าเว็บอ่าน: `propose` `borrow` `held` `heldDate` `claim` `paid` `summary` `note`

ค่าที่นับว่าติ๊กแล้ว: TRUE, ใช่, 1, x
